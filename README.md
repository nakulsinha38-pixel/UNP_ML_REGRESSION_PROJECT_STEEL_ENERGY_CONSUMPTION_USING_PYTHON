# UNP_ML_REGRESSION_PROJECT_STEEL_ENERGY_CONSUMPTION_USING_PYTHON

I completed this project as part of my Data Science and Machine Learning Internship with United Network of Professionals (UNP), and it was executed as a collaborative group project.

1. Project Overview: The project focused on predicting energy consumption (Usage_kWh) in a steel industry using machine learning techniques.

2. Dataset: We used electricity consumption data from DAEWOO Steel Co., Gwangyang, South Korea, containing 35,040 records collected at 15-minute intervals during 2018.

3. Objective: The main objective was to predict industrial energy consumption and understand the relationship between electrical parameters and energy usage.

4. Data Preprocessing: We checked for missing values and duplicates, removed unnecessary columns, encoded categorical variables, and scaled the features using StandardScaler.

5. Data Visualization: We used histograms, boxplots, count plots, regression plots, and correlation heatmaps to understand data patterns and relationships.

6. Feature Analysis: We analysed reactive power, power factor, week status, and load type to identify their influence on energy consumption.

7. Feature Selection: We performed a Variance Inflation Factor (VIF) analysis to identify and remove highly correlated features.

8. Machine Learning Models: We implemented Linear Regression, Decision Tree, Random Forest, KNN, Support Vector Regression, Bayesian Ridge, Gradient Boosting, XGBoost, and AdaBoost.

9. Model Evaluation: We evaluated the models using MAE, MSE, RMSE, MAPE, and R² score.

10. Train-Test Splitting: We compared model performance using five different data splits: 80-20, 75-25, 70-30, 65-35, and 60-40.

11. Artificial Neural Network: We developed ANN models using TensorFlow with different architectures, ReLU activation, and Adam and SGD optimizers.

12. Best ANN Model: The architecture with 128 and 64 hidden neurons, Adam optimizer, 20 epochs, and batch size 32 achieved an R² score of 0.9950.

13. Model Comparison: Random Forest and XGBoost consistently delivered the best results, with XGBoost achieving an R² score of 0.9968 in the 80-20 split.

14. Applications: This project can help steel industries forecast electricity consumption, monitor energy usage, and support better energy planning and management.

15. Learning Outcome: Through this collaborative project, I gained practical experience in data preprocessing, exploratory data analysis, feature selection, machine learning algorithms, neural networks, and model evaluation using Python.
